## ① 圆头胶囊 `TCPDrawBadgePill`（Badges.m:592–642）

**内存**：`CGImageCreateWithImageInRect` 产出的 `leftCG` / `rightCG` 各自在使用后立即
`CGImageRelease`（633、638 行），两段互不依赖，`leftCG == NULL` 时 `rightCG` 仍会被正确处理。**无泄漏。**

**越界**：
- `cap` = `MIN(side, asset.size.width)`，`capPx` 被夹到 ≥1，`capI` 再夹到 `[1, pw]`（624–625 行）；
- 右段起点 `pw - capI ≥ 0`，宽度 `capI`，右边界正好落在 `pw`。**不越界。**

**正确性隐患（不是崩溃，是显示）**：中间段填充依赖 `TCPBadgeAssetFillColor(asset)` 返回非 nil
（607 行）。若素材本色取不到（全透明 / 四角采样失败），`if (fill != nil)` 整段跳过，
于是两端圆头盖上去、**中间是空的** —— 多位数字角标会「断成两半」。当前 25×25 正圆素材取得到，
所以实测没暴露。建议：`fill == nil` 时退回 `TCPDrawAssetAspectFitted` 整段铺满，别留空。

**精度瑕疵（不影响结果）**：622 行 `capPx` 把 `cap`（点）与 `ph`（像素）混算比例，
只影响圆头裁剪的像素宽度取整，形状不变。

## ② `TCPClockTick` 每 30 秒遍历窗口树（Icons.m:850–875，Main.m:283–310）

**代价**：从 `UIApplication.sharedApplication.windows` 起广度遍历，节点上限 4000（走不满，桌面时是几百），
命中 `SBHClockApplicationIconImageView` 才 `TCPClockViewApply` 重画一张 60×60 表盘。
30 秒一次、主队列、A11 上可忽略。

**已有守卫**：
- 首行非主线程就 `dispatch_async` 回主队列（851–854 行）；
- `store.active && iconsEnabled` 为假立即 return（856 行）—— 关主题后零开销；
- 定时器是**文件级静态持有**（297 行），避开了 0.9.17 那次「局部 `dispatch_source_t` 被 ARC 释放 → tick=0」的坑；
- 只在 SpringBoard 里起（287 行判 bundle id）。

**结论：不会在锁屏/后台「额外」跑错东西，但确实没有锁屏/后台判断。**
锁屏后 SpringBoard 仍然活着（锁屏就是它管的），所以会继续每 30 秒遍历一次并重画。
这是**不必要的常驻开销，不是错误**，用户没报耗电，**不建议现在改**。
将来要省电，加一条 `UIApplication.sharedApplication.applicationState == UIApplicationStateActive`
或锁屏通知守卫即可，改动很小。

## ③ `TCPCompositeCalendarInk` 的 mask context 参数（Icons.m:590–654）

**mask context 参数正确**：
- `CGBitmapContextCreate(maskBuffer, dw, dh, 8, dw * 4, 设备RGB, kCGImageAlphaNoneSkipLast)` ——
  `bytesPerRow = dw*4` 与 RGBA 排布一致；RGB 色彩空间配 `kCGImageAlphaNoneSkipLast` 合法（跳过末字节）。
- `CGContextClipToMask(ctx, rect, maskImage)` 用**亮度**当遮罩强度，而 629–631 行把 `v` 同时写进 R/G/B 三通道，
  所以强度是按设计生效的。**正确**。
- 墨层判定：与四角平均色距离 > 0.02 才算墨（627 行），深底填白、亮底填黑（648 行），
  避免了「白底黑字压深色底 = 看不见字」和 multiply/screen 混合模式的问题。

**释放全配平**，含早退路径：
`space`→Release（603）、`tmp`→Release（606）、`buffer`→free（634，两处早退 604 行也 free），
`maskSpace`→Release（641）、`maskCtx`→Release（644）、`maskImage`→Release（651）、`maskBuffer`→free（653）。
`maskCtx == NULL` 早退时 buffer 已在 634 行释放过，不会再 free —— 正确。

**边界**：`corners` 用 `dw-1` / `dh-1`，而 594 行已保证 `sw, sh ≥ 1` → `dw, dh ≥ 1`，不下溢。

**一处可留意（非缺陷）**：样本被限制在 96×96（596–597 行）。60×60@2 = 120×120 的系统日历图会被缩到 96×96
再取墨，边缘抗锯齿像素可能被判成墨；实测 `dyn{ink:w,lum=0.14,cov=0.82}` 说明结果可用。
