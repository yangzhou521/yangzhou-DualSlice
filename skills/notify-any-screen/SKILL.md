# 任何界面都要用灵动岛胶囊告知用户；要拍板的事立即弹窗

用户 2026-10-31 15:48 / 15:50 / 15:51 / 15:53 / 15:56 定，**所有对话、所有工程永久适用**（原话：「不能访问我的仓库时给我说一声你来个通知或者弹窗让我知道这个！」「通知和弹窗都行让我知道啊」「对了无论任何界面都要给我一个通知或者弹窗」）。

2026-11-01 08:59 补（用户原话「你这边需要我确认的立即给我弹窗要不然我不知道」，**所有工程、所有对话、永久适用**）：凡卡在「等用户点头才能继续」的地方，一律当轮弹确认框，不能只等在对话里回文字。

## 铁律

1. **凡需要让用户知道的事**（push 前后、任务完成、失败、阶段进度、需要用户点头），无论用户此刻在任何界面（Apelin 内 / 桌面 / 别的 App），都必须让他真看见。
2. **凡需要用户拍板确认的事**（上传/推送、合并版本、装包、注销、开 VPN、删某样东西、要不要继续下一步），**立即当轮弹确认框**，别只等文字回复。

## 三种手段的分工（关键，别搞混）

| 手段 | 什么时候用户看得到 | 用途 |
| --- | --- | --- |
| **灵动岛纯文案胶囊** `sh scripts/hud-notify.sh 8 "!文案"` | **任何界面都看得到** —— CountdownHUD 注入 SpringBoard 画的顶层窗口（windowLevel 最高、跨 Apelin/桌面/别的 App 盖得住） | 要「任何界面都让用户看见」的唯一保底手段，优先用它做**告知** |
| **灵动岛确认弹窗** `sh scripts/respring-guard.sh --ask <秒> <标签>`（`?` 模式，按钮「立即注销」） | 任何界面都看得到，且**带按钮**，用户得点一下 | **要用户拍板/点头**的动作：上传、装包、注销、开 VPN、删东西、继续下一步。标签里写清确认的是什么事 |
| `apelin_notification_send` | 只在 Apelin 不在前台时显示；Apelin 在前台时横幅被自己的通知代理吞掉 | 用户切去别的对话/桌面/别的 App 时的补充提醒 |

**「无论任何界面都要给通知或弹窗」= 必须写灵动岛胶囊**，不能只发 `apelin_notification_send`（那条用户人在 Apelin 里时根本看不到）。

**「需要用户确认」= 必须用 `?` 确认弹窗**，不能只发纯文案胶囊（纯文案不让人「确定」），更不能只靠在对话里问一句就干等。

## 做法（固定顺序）

### A. 只是告知（不等人决定）

1. **正文写清**。
2. **写纯文案胶囊**：`sh scripts/hud-notify.sh 8 "!<一句话>"`
   - `!` 前缀 = 纯文案（不倒数、不注销、不装包，绿色，最长 32 字）
   - 可带秒数 `sh scripts/hud-notify.sh 12 "!文案"`（3~60 秒，默认 8）
   - 可带对话 id 让胶囊可点：`HUD_SID=<sid> sh scripts/hud-notify.sh 8 "!文案"`
3. 可选再发 `apelin_notification_send`（补充，不能替代胶囊）。

### B. 要用户拍板确认（立即弹窗）

1. **正文写清**：为什么 / 多久 / 下一步。
2. **当轮就弹确认框**：`sh scripts/respring-guard.sh --ask <秒> <标签>`（`?` 模式）。
   - 按钮文案是插件固定的「立即注销」，所以**标签里写清楚要确认的到底是什么事**（如「上传 1.0.13 到 GitHub」）。
   - 弹窗返回后按退出码：`0`=用户确认（继续做）；`4`/`5`=取消或超时（**什么都不做，绝不自动继续**）。
   - 若只是要用户做纯选择、不做设备动作，用 `sh scripts/vpn-guard.sh <秒> <标签>`（同样弹窗，但不触发注销）。
3. 用户点完，正文仍要写清结论与下一步——弹窗只解决「让用户在屏幕上看见并做选择」，不替代说明。

## 边界

- 纯文案胶囊是「告知」用，不做破坏性动作；要用户点头的动作走 `?` 确认弹窗。
- `apelin_notification_send` 每回合 ≤3 条、间隔 ≥30 秒；胶囊不受此限但别刷屏。
- 确认弹窗依赖 CountdownHUD 1.5.0+；没装时 `?` 写不出去（退出码 6），退回正文说明。
- 弹窗超时 = 什么都不做、绝不自动继续；取消 = 什么都不做。

## 与其它技能的关系

- `notify-before-git-push`：push 前后告知、先试 push 不通才请开 VPN。
- `task-done-notify`：任务完成/阶段进度的胶囊+通知。
- `respring-confirm-via-island-popup`：`?` 确认弹窗的调用细节与退出码。
