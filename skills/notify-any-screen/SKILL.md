# 任何界面都要告知；要拍板的事立即弹窗

用户定的，**所有对话、所有工程永久适用**。原话：「无论任何界面都要给我一个通知或者弹窗」
「你这边需要我确认的立即给我弹窗要不然我不知道」「请求截图看桌面实际样子，这种要截屏的要求以后给我弹窗」
「每次修好之后都要在对话里给我汇报✅」。

## 铁律

1. **凡需要用户知道的事**（任务完成、失败、阶段进度、push 前后），无论他在 Apelin 内 / 桌面 / 别的 App，
   都必须让他真看见。
2. **凡需要用户拍板的事**（上传推送、合并版本、装包、注销、开 VPN、删东西、继续下一步、
   **截图取证**），**立即当轮弹确认框**，别只等文字回复。
3. **截图必须先弹窗确认**，用户点头才截，一次同意只覆盖一次截图。

## 三种手段的分工

| 手段 | 用户什么时候看得到 | 用途 |
|---|---|---|
| **灵动岛纯文案胶囊** `sh scripts/hud-notify.sh 8 "!文案"` | 任何界面 | **告知**的保底手段，优先用它 |
| **灵动岛确认弹窗** `sh scripts/respring-guard.sh --ask <秒> <标签>` | 任何界面，带按钮 | **要用户点头**：上传、装包、注销、开 VPN、删东西、截图 |
| `apelin_notification_send` | 只在 Apelin 不在前台时 | 补充，**不能替代胶囊** |

**「任何界面都要通知」= 必须写胶囊**（`apelin_notification_send` 在 Apelin 前台时根本看不到）。
**「需要确认」= 必须用 `?` 弹窗**（纯文案不让人「确定」）。

## A. 只是告知（不等人决定）

1. **正文写清**（第一句就是结论）
2. **写胶囊**：`sh scripts/hud-notify.sh 8 "!<一句话>"` —— `!` 前缀=纯文案，绿色、不注销不装包，最长 32 字；
   秒数 3~60（默认 8）；可带对话 id 让胶囊可点：`HUD_SID=<sid> sh scripts/hud-notify.sh 8 "!文案"`
3. 可选 `apelin_notification_send`（≤3 条/回合，间隔 ≥30 秒）

## B. 要拍板（立即弹窗）

1. 正文写清：为什么 / 多久 / 下一步
2. 当轮弹窗：`sh scripts/respring-guard.sh --ask <秒> <标签>`。
   按钮文案固定是「立即注销」，所以**标签里写清要确认的到底是什么事**。
   退出码：`0`=确认（继续做）；`4`=取消 / `5`=超时 → **什么都不做，绝不自动继续**。
   纯选择不涉及设备动作，用 `sh scripts/vpn-guard.sh <秒> <标签>`。
3. 用户点完，正文仍要写清结论与下一步。

## 截图四步铁律（2026-11-02 05:05，当场抓到截到 Apelin 自己界面）

① **先确认目标在前台**：桌面就 `icli button home`，别的 App 就 `uiopen --bundleid <bid>` 拉到前台；
**不是目标就别截**。② 说清「截什么、给谁看、验证什么」，等当次点头。③ 截完**立刻核对拍的是目标**。
④ 界面树读不到桌面图标细节（日历格子/文件夹）时，改靠诊断键 + 用户口述，别硬截。

## 边界

- 胶囊是「告知」用，不做破坏性动作；要点头的走 `?` 弹窗。
- 弹窗依赖 CountdownHUD 1.5.0+；没装时 `?` 写不出去（退出码 6）→ 退回正文说明。
- **安全模式**下胶囊与弹窗都不显示 → 只走正文 + `apelin_notification_send`（真系统通知，实测可用）。
- 弹窗取消/超时**不算拒绝**，下一轮继续提并再弹。
