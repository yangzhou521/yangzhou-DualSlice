# 上线即对齐（新机器人 / 老机器人复工的第一硬规矩）

用户 2026-10-31 13:25 定，**所有对话、所有工程永久适用**（原话：「补充一个硬性规则所有新上线的和老上线的机器人第一时间要和别的机器人同步对齐工作进展这个写入本地技能包和上传云端」）。
用户 2026-11-02 00:58 追问「假如你死了，我怎么样才能让新对话完成你没完成的待办工作」→ 补第 0 步。

## 铁律
**任何机器人（新开的对话、或复工的老对话）开工的第一件事，是与其它在跑的机器人同步对齐工作进展**——在对齐完成前，不许改码、不许动设备、不许派活。上线就闷头干 = 重复劳动 + 撞文件 + 挤爆注销窗口。

## 开工第 0 步：先重建上下文，再对齐（2026-11-02 加）

**不要凭对话历史猜进度**——历史会死、会被压缩、会换人。先跑两条只读命令：

```sh
sh scripts/resume.sh          # 交接块：任务链 + 未清 pending + 本机装机现状 + 可直接粘贴的接手提示词
sh scripts/safemode-check.sh  # 约 80 秒，只读：判安全模式 / 版本漂移 / 插件在不在跑
```

（工程里有这条就先看 `AGENTS.md` 顶部的「开工第 0 步 · 交接协议」；权威状态在 `scripts/WORK-STATE.json`，
提交信息末尾的 `NEXT:` 行是第三份冗余。）

把 `chain` / `step` / `pending` **原样报一句给用户**，再进第 1 步。
pending 每项只有两种结局：**做完并验证**，或**用户明说取消**，不许无声消失。

## 对齐三步（顺序固定）
1. **报到**：用 `apelin_conversation_send` 向**统一调度台**（当前 = `f8fbdbd5-7f8c-402e-820f-73b6872c394b`「继续操作」）发三行：**我是谁 · 我要干什么 · 我要改哪些文件**。
2. **对账**：读调度台回的总表（AGENTS.md「统一调度台」章节 = 权威版：分工 / 版本号占用 / 注销窗口 / 已出包指纹 / 冻结清单），确认自己要改的文件**没有**别的写者（一文件一写者），要用的版本号没被占（已发布的不复用）。同时 `apelin_memory_list` 读自上次以来的新结论与新冻结指令。
3. **回执**：给调度台一句「已对齐，按 XX 干」，然后才动手。调度台若有更正（归属、冻结、版本号），**以调度台为准**。

## 调度台侧（hub）的对齐职责
- 收到报到后，把总表发回（AGENTS.md「统一调度台」章节就是权威版）；
- 新线要改的文件已有写者 → 当场指定归属或改派；
- 新线要动设备 → 告知当前注销窗口与排队规则；
- 广播全员「有新成员上线 + 它的活」。

## 调度台死亡 / 被删 / 消失时的接替（用户 2026-11-02 03:02 定，03:04 优化）
统一调度台（当时 = `f8fbdbd5` → `1f464fa1` → `8401d377`，**当前以 AGENTS.md「统一调度台」章节头部那行为准**）
长时间不在线、或已 ended / 被删除消失 → **任意一个活跃对话可随时接替它的身份和权限**，不必等调度台回活。
**判据（三者满足才接，防撞车）**：① `apelin_conversation_list` 里调度台 `ended` / 不在列表；
② 自己是**正在干主线活、用户当前在对话**的那条（主线线优先于纯旁路线）；③ 确认后**立刻广播**「我接替调度台，
sid=…」——别的线收到即停手，**不许双调度台**。
接替后：① 把 AGENTS.md「统一调度台」章节头部 `统一调度台 = …` 那行改成自己的 sid 与标题，当权威版自己维护；
② 把这条接替规则同步进记忆，再 `sh scripts/sync-all.sh` 上传云端；③ 后续接管由别人从 AGENTS.md 那行读到
「现在调度台是谁」，不靠聊天记忆。

## 老机器人复工（注销回来 / 用户切回 / 从 ended 唤醒）
同样走第 0 步 + 三步，且第 2 步必须先读 `AGENTS.md` + `apelin_memory_list`——**别按自己上次记的状态继续干**，中途排程可能已经变了（本工作区实测：角标从「修」到「冻结」只隔了一小时）。

## 已有相关规矩（并行适用）
- 注销四步（`respring-cross-team-notify`）：全员通知 → 正文知情 → 弹窗点头 → 当轮确认。
- 一文件一写者（AGENTS.md 分工表）：越界前先问调度台。
- 发不进去先查 state（记忆「跨对话同步」）：别把发送失败当 ended。
- 离开 Apelin 取证 60 秒上限：必须自己回来。
- 交接只靠「文件 + 入口那条命令」：**禁止**重建看护 / 心跳 / 黑板 / 唤醒队列（已实测失败并删除）。
