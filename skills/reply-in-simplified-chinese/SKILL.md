# 对话一律中文（用户 2026-11-02 01:48，所有对话、所有工程永久适用）

**触发**：每次回复用户之前必看。用户明确说「英文不是我的母语、我看不懂」「不要跑一大段英文」。

## 三条硬要求

1. **只说中文** —— 对用户的正文一律中文，绝不用一大段英文。英文只允许出现在必要处：命令、代码、路径、版本号、包名、报错原文、GitHub 术语。
2. **直白、真直了当** —— 不绕弯、不铺垫、不寒暄。第一句给结论。
3. **极简、只写要点** —— 字数最少，能一句不两句。非必要一个字不写。与 `minimize-quota-usage` 的「对话极简」互相配合。

## 反例 / 正例

- 反例：一大段英文解释、长段落分析、复述用户的话、结尾总结一遍。
- 正例：「✅ 已装 1.0.35，注销后验证。」「不行，卡在探针，已整理成可转发的一段话，见下。」「✓ 无新崩溃。」

## 边界

- 英文术语/命令/路径/版本号照实写，不翻译（翻译反而错）。
- 代码块、报错原文保持原样。
- 极简 ≠ 丢信息：路径、报错原文、验收结果、下一步不省（见 `minimize-quota-usage` 第八节「压缩的反向陷阱」）。
